# Aprov Black — Cartão Corporativo com Inteligência Artificial

Landing page da Aprov Black organizada para desenvolvimento local.

## Estrutura do Projeto

```
Winden/
├── index.html          ← Página principal
├── assets/
│   ├── css/
│   │   ├── main.css    ← Estilos principais (Webflow)
│   │   └── slick.css   ← Estilos do carrossel
│   ├── js/
│   │   ├── jquery.min.js
│   │   ├── jquery-1.11.0.min.js
│   │   ├── jquery-migrate.min.js
│   │   ├── slick.min.js
│   │   ├── webflow.js
│   │   ├── webflow.chunk1.js
│   │   ├── webflow.chunk2.js
│   │   └── analytics.js
│   └── images/
│       └── *.webp / *.png
└── README.md
```

## Como Rodar

Abrir `index.html` diretamente no browser, ou usar um servidor local:

```bash
# Com Python
python -m http.server 3000

# Com Node (npx)
npx serve .
```
